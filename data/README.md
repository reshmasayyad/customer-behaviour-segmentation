# Data provenance

Source: Daqing Chen, *Online Retail II*, UCI Machine Learning Repository, DOI https://doi.org/10.24432/C5CG6D.

Official dataset page: https://archive.ics.uci.edu/dataset/502/online+retail+ii

Official ZIP: https://archive.ics.uci.edu/static/public/502/online+retail+ii.zip

Dataset license: CC BY 4.0. Cite the dataset when reusing this analysis. Raw data and customer-level derived tables are kept out of Git; aggregate findings and figures are committed.

The workbook contains two worksheets. Both must be loaded. Monetary values are in GBP. Cancellation invoices, missing customer identifiers and non-merchandise entries require explicit handling.
