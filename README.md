# Customer Behaviour Segmentation

Identify customer purchasing patterns using RFM features, compare K-means and Gaussian mixture models, and measure model stability and customer movement across time.

Dataset: [UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii), two years of UK online retail transactions.

The project separates robustness of the clustering model from changes in individual customer behaviour. Evaluation uses unsupervised metrics and future purchasing observations; no labelled customer segments are assumed.
